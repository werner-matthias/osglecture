# TUC-2019 — A Theme for ltx-talk

A LaTeX package that provides an unofficial version of the TU Chemnitz presentation theme for `ltx-talk`.
It uses `ltxtalk-theme`.

Use `fonts=roboto` to activate the coordinated corporate font bundle: Roboto
for body copy and headings, compact Inconsolata for code, and Fira Math for
Unicode mathematics. Without the option, the document's existing fonts are
left unchanged.

This package is part of the osglecture bundle.
