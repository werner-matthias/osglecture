# TUC-2019 — A Theme for ltx-talk

`ltxtalk-theme-tuc-2019` provides an unofficial TU Chemnitz presentation
theme for the `ltx-talk` class. It is built on `ltxtalk-theme` and offers the
university layout, faculty-aware colours, and an optional coordinated font
selection.

This package is part of the `osglecture` bundle.
