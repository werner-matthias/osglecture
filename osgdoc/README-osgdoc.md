# osgdoc — Small Tools for Documentation

This LuaLaTeX package provides a thin wrapper around the `cnltx-doc` class,
as well as a few additional macros for documentation, especially the automatic
documentation of TeX and Lua source code.

For documentation, see `osgdoc-en.pdf` or `osgdoc-de.pdf`.

This package is part of the osglecture bundle.
