# tagbridge

`tagbridge` improves tagged-PDF output from selected third-party packages that
do not yet provide suitable native support. It currently supplies compatibility
for QR codes and self-contained TikZ graphics, avoiding warning floods and
anonymous or misleading PDF structures.

The package is deliberately transitional: compatibility code is removed when
the corresponding upstream package or LaTeX's tagged-PDF support gains a
native solution.

This package is part of the `osglecture` bundle. For the supported packages and
user interface, run `texdoc tagbridge`.
