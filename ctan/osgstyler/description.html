osgstyler provides reusable, template-based styles for LaTeX documents. It keeps semantic choices in document code independent of the fonts, colours, measurements, decorations, and inline rendering chosen by a visual theme.

Named palettes and portable roles make themes interchangeable across document types. Ordered colour series support material whose colours distinguish data or categories, and named decorations describe lines, backgrounds, frames, margin marks, and affixes without binding them to one way of rendering.
