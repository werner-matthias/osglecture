Notes for the CTAN team and the TeX distribution maintainers

1. Package layout and installation
   osglecture.tds.zip contains the complete installation tree; all paths
   in items 2 to 4 refer to it.
   The package directory mirrors the development repository: one
   directory per module with its sources, documentation (PDF), tests, and
   l3build file, plus the top-level build.lua. In the unpacked package,
   "l3build install", "l3build doc", and "l3build check" therefore work
   as in the repository. Without l3build, run "luatex <file>.dtx" on every
   .dtx file except osglecture/osglecture-adapters.dtx and
   osglecture/osglecture-profiles.dtx: all other .dtx files are
   self-extracting (there are no .ins files), and osglecture.dtx also
   extracts those two.
   The example projects in examples/ are installed as
   doc/luatex/osglecture/examples.

2. Executable script ollm
   The bundle contains the build manager ollm, a Perl script (Perl 5.30 or
   later). Please install it as a user command:
   - script:   scripts/osglecture/ollm  (no file extension)
   - libraries: scripts/osglecture/lib, scripts/osglecture/vendor,
     scripts/osglecture/definitions, scripts/osglecture/ollm-latexmk.rc;
     ollm finds them relative to its own location (FindBin), so only the
     script itself needs a link in the binary directory.
   - Windows: scripts/osglecture/ollm.cmd is the launcher for manual
     installations. For TeX Live's runscript wrapper the script may need a
     .pl extension; please tell us if you prefer it renamed.
   ollm calls latexmk and lualatex.

3. Manual page
   doc/man/man1/ollm.1 is the manual page of ollm.

4. Vendored third-party code (unchanged copies)
   - TOML-Tiny 0.22 (CPAN; same terms as Perl 5) and toml2lua (MIT, from
     expltools). Details: ollm/THIRD_PARTY-ollm.md and
     osglecture/THIRD_PARTY-osglecture-cls.md.

5. Engine
   The bundle generally requires LuaLaTeX; for details see
   https://github.com/werner-matthias/osglecture#modules-version-and-compatibility
