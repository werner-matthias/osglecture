The osglecture bundle supports the generation of lecture materials. It can produce several documents from one LaTeX source: slides, handouts, a presenter version, or script, each in several languages. The class osglecture selects the actual document class (e.g. ltx-talk or beamer for presentations, book or scrbook for long forms) through document profiles, so the source contains nothing class-specific. The build manager osgdocmk builds whole lecture series, carries cross-references and counters between units, and collects units into one document. In addition, the bundle aims at accessible, tagged PDFs.

The bundle requires LuaLaTeX and is under active development.
