The osglecture bundle supports the generation of lecture materials. It can produce several documents from one LaTeX source: slides, handouts, a presenter version, or script, each in several languages. The class osglecture selects the actual document class (ltx-talk or beamer for presentations, book or scrbook for long forms) through document profiles, so the source contains nothing class-specific. The build manager osgdocmk builds whole lecture series, carries cross-references and counters between units, and collects units into one document. In addition, the bundle aims at accessible, tagged PDFs.

Several of the bundle's packages can also be used on their own. The bundle currently contains:

  • osglecture: document class that produces slides, script, handouts, and other materials from a common source
  • osgdocmk (OSG Lecture Document Maker): latexmk-based build manager for creating and deploying lecture materials
  • osgmodes: portable document modes in the style of beamer/ltx-talk for arbitrary classes
  • langselect: several language versions of a document from a common source
  • tagpax: semantic import of tagged PDFs
  • osgstyler: template-based formatting
  • lttalk-themeengine: theme engine for ltx-talk, with a few themes modelled after Beamer themes
  • lttalk-theme-tuc-2019: unofficial version of the TU Chemnitz presentation theme for ltx-talk
  • ansiterm: ANSI-aware, optionally executable terminal windows
  • osglistings: minted-based code-listing front end
  • semcat: semantic-category markup
  • tagdirtree: taggable directory trees
  • osgdoc: small wrapper for cnltx with further support for documentation

The bundle requires LuaLaTeX and is under active development.
