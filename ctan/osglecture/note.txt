Notes for the CTAN team and the TeX distribution maintainers

1. Executable script osgdocmk
   The bundle contains the build manager osgdocmk, a Perl script (Perl 5.30 or
   later), in osgdocmk/scripts. Please install it as a user command:
   - script: osgdocmk/scripts/osgdocmk (no file extension), installed as
     scripts/osgdocmk/osgdocmk
   - libraries: lib/, vendor/, definitions/, and osgdocmk-latexmk.rc next to
     it; osgdocmk finds them relative to its own location (FindBin), so only
     the script itself needs a link in the binary directory.
   - Windows: osgdocmk.cmd is the launcher for manual installations. For TeX
     Live's runscript wrapper the script may need a .pl extension; please
     tell us if you prefer it renamed.
   osgdocmk calls latexmk and lualatex.

2. Manual page
   osgdocmk/man/osgdocmk.1 is the manual page of osgdocmk.

3. Vendored third-party code (unchanged copies)
   - TOML-Tiny 0.22 (CPAN; same terms as Perl 5) and toml2lua (MIT, from
     expltools). Details: osgdocmk/THIRD_PARTY-osgdocmk.md and
     osglecture/THIRD_PARTY-osglecture-cls.md.

4. Engine
   The bundle generally requires LuaLaTeX.
