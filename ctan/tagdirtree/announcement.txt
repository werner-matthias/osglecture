tagdirtree typesets accessible directory-tree listings.
Unlike packages that draw the complete tree as a graphic, it represents the hierarchy
directly as a nested list of readable text, so the visual indentation and optional
file-type icons complement rather than replace the document structure.

tagdirtree was originally included in the osglecture bundle. Since it can run
independently, it is now released as a separate package, so that it can be installed
without the rest of the bundle.
