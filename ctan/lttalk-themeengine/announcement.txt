lttalk-themeengine is a theme engine for the ltx-talk presentation class. It separates layouts, colours, and fonts so that complete designs can be selected, combined, and adapted without tying document content to a particular visual theme.

lttalk-themeengine was originally included in the osglecture bundle. Since it can run
independently, it is now released as a separate package, so that it can be installed
without the rest of the bundle.
