langselect helps maintain two or three language versions of a document in a single LaTeX source.
Shared passages remain shared, while language-dependent text is selected for the requested output language.
Language-independent elements (such as mathematical formulas or LaTeX references) need to be specified
only once and can be inserted anywhere in the language versions.

langselect was originally included in the osglecture bundle. Since it can run
independently, it is now released as a separate package, so that it can be installed
without the rest of the bundle.
