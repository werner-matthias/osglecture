osgdoc is a LuaLaTeX class and package for documenting TeX and Lua source code. The class is a thin wrapper around the cnltx-doc class, the package loads parts of cnltx. Both add a few macros for documentation, especially for the automatic documentation of TeX and Lua source code.

osgdoc was originally included in the osglecture bundle. Since it can run
independently, it is now released as a separate package, so that it can be installed
without the rest of the bundle.
