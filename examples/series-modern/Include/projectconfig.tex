% langselect's target language is bridged from OLLM's own per-language
% build value (\OsgLectureLanguage is not yet defined this early in class
% loading, but the build-spec accessor it is built from already is), so a
% single langselect-aware source produces the correct language without any
% further per-target configuration.
\OsgLectureBuildLoadedTF
  { \edef\olsTargetLanguage{\OsgLectureBuildValue{language}} }
  { }
% projectconfig.tex is read while osglecture.cls is still loading, before
% its own \LoadClass for the target's base class (here ltx-talk) has run.
% Loading a package here that itself probes "does the base class already
% define X" -- as langselect's default 'unified shorthands' does via
% csquotes, which checks for an existing 'quote' environment -- gets a
% false negative and installs its own fallback, which then collides with
% the base class's own definition once \LoadClass does run
% ("Environment 'quote' already defined"). \AtEndOfClass defers this
% \RequirePackage (and anything depending on it, like \title using
% \lende) to the end of osglecture.cls's own body, i.e. after its nested
% \LoadClass has already completed -- the general-purpose fix for any
% \usepackage call placed here, not specific to langselect.
\AtEndOfClass{
  \RequirePackage[languages={en,de}]{langselect}
  \title{\lende{One source, multiple documents}{Eine Quelle, mehrere Dokumente}}
}

  }
}
