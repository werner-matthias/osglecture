# lttalk-theme — Themes for ltx-talk

`lttalk-themeengine` is a theme engine for the `ltx-talk` presentation class. It
separates layouts, colours, and fonts so that complete designs can be selected,
combined, and adapted without tying document content to a particular visual
theme.

The package includes several ready-to-use presentation layouts, colour-only
themes, and coordinated font themes. Its slot-based layout and semantic colour
and font roles also support project-specific themes and accessible tagged
output.

For a (English and German) description of the bundled themes,
customization, accessibility options, and complete interface, run `texdoc lttalk-themeengine`.

## Dependencies

Dependencies on other packages of this project and on selected third-party
packages; the usual LaTeX packages the code loads itself are not listed.

- Required at run time: `osgstyler`, `ltx-talk` 0.5.3 or later
- Required to build the documentation (`l3build doc`): `langselect`, `osgdoc`, `osgstyler`, `ltx-talk` 0.5.3 or later
- Required to run the test suite (`l3build check`): `osgstyler`, `ltx-talk` 0.5.3 or later

This package is developed in the course of the osglecture document class and shares the same repository, see https://github.com/werner-matthias/osglecture. The class does not require it, and it works on its own.
