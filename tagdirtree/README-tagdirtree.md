# tagdirtree

`tagdirtree` typesets accessible directory-tree listings. Unlike packages that
draw the complete tree as a graphic, it represents the hierarchy directly as
a nested list of readable text. The visual indentation and optional file-type
icons therefore complement rather than replace the document structure.

With tagged PDF enabled, entries retain their kind, name, note, and
parent-child relationship for assistive technology. The package works in any
LaTeX document and does not depend on the `osglecture` class.

For the complete interface and examples, run `texdoc tagdirtree`.
