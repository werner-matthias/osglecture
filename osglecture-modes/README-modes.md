# osglecture-modes — Portable document modes for LaTeX

`osglecture-modes` lets authors share content between presentations, handouts,
scripts, and other document variants without committing the source to one
document class. It brings Beamer/`ltx-talk`-style mode selection to ordinary
LaTeX classes and supports project-defined modes with shared parent modes.

Besides conditional passages, the package provides mode-dependent values and
commands as well as integration with overlay-aware presentation classes.
Optional source filtering is available with LuaLaTeX.

See the [German manual](../doc/osglecture-modes-de.pdf) or
[English manual](../doc/osglecture-modes-en.pdf) for examples and the complete
interface.
