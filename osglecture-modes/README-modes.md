# osglecture-modes - geneeraization of document modes in the style of beamer/ltx-talk

This package provides a generalization document modes as known from beamer or ltx-talk.
There are two differences to beamer/ltx-talk modes:
- One can create new modes
- The modes may form a dag, not only a tree.

This package is part of the osglecture bundle.
