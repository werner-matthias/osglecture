# osglecture-modes — Generalization of Document Modes in the Style of Beamer and ltx-talk

This package generalizes the document modes provided by Beamer and ltx-talk.
There are two differences from Beamer and ltx-talk modes:

- Users can create new modes.
- The modes may form a directed acyclic graph (DAG), not just a tree.

This package is part of the osglecture bundle.
